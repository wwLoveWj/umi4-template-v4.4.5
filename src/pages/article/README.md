# 文章系统

## 功能特性

### 1. 文章列表页面 (`/article`)

- **顶部 Tabs 分类**：支持推荐、JavaScript、CSS、GitHub、Git、React、Vue、Vite、Webpack 等分类
- **文章卡片展示**：包含封面图、标题、摘要、作者信息、阅读量、点赞数等
- **无限滚动加载**：支持分页加载更多文章
- **实时交互**：支持点赞、收藏操作，状态实时更新
- **响应式设计**：适配移动端显示

### 2. 文章详情页面 (`/article/detail/:id`)

- **完整内容展示**：支持 HTML 内容渲染，包含代码高亮、图片、表格等
- **评论系统**：支持查看评论、发表评论、点赞评论
- **底部操作栏**：固定底部的点赞、收藏、评论按钮
- **评论弹窗**：点击评论输入框弹出评论发表界面

### 3. 收藏文章页面 (`/article/collections`)

- **收藏列表**：展示用户收藏的所有文章
- **取消收藏**：支持取消收藏操作
- **空状态处理**：当没有收藏文章时显示空状态页面

## 技术实现

### 1. 类型定义

- 在 `src/types/API.d.ts` 中定义了完整的文章系统类型
- 包含文章、评论、分类等所有相关类型

### 2. API 服务

- 在 `src/service/api/article.ts` 中实现了所有文章相关 API
- 目前使用模拟数据，可以轻松替换为真实 API

### 3. 模拟数据

- 在 `src/utils/mockArticleData.ts` 中提供了完整的模拟数据
- 包含 8 篇示例文章和评论数据

### 4. 路由配置

- 在 `src/routes/menuRoutes.ts` 中添加了文章相关路由
- 支持文章列表、详情、收藏页面的路由跳转

## 使用说明

### 1. 访问文章列表

- 在底部导航栏点击"文章"进入文章列表页面
- 可以通过顶部 Tabs 切换不同分类的文章

### 2. 查看文章详情

- 点击文章卡片进入详情页面
- 在详情页面可以点赞、收藏、发表评论

### 3. 查看收藏文章

- 在个人中心点击"收藏"进入收藏页面
- 或者在文章详情页面点击收藏按钮

## 样式设计

- 卡片式布局，圆角设计
- 响应式图片展示
- 优雅的加载动画

### 2. 文章详情样式 (`src/pages/article/detail.less`)

- 清晰的内容层次
- 代码块和引用样式
- 固定底部操作栏

### 3. 收藏页面样式 (`src/pages/article/collections.less`)

- 与列表页面保持一致的视觉风格
- 特殊的取消收藏按钮样式

## 扩展功能

### 1. 搜索功能

- 可以在文章列表页面添加搜索框
- 支持按标题、内容、标签搜索

### 2. 标签筛选

- 可以添加标签筛选功能
- 支持多标签组合筛选

### 3. 分享功能

- 可以添加文章分享功能
- 支持分享到社交媒体

### 4. 离线阅读

- 可以添加文章缓存功能
- 支持离线阅读已收藏的文章

## 注意事项

1. 目前使用模拟数据，实际使用时需要替换为真实 API
2. 图片使用了 Unsplash 的随机图片服务，实际使用时需要替换为真实图片
3. 评论功能目前只支持一级评论，可以扩展为多级评论
4. 点赞和收藏状态目前只在前端维护，实际使用时需要与后端同步
